# 空间试验箱结论（pilot-01 / 02 / 03 + 成片审计，2026-09-23）

## 一句话结论

**四轮实验把三条"控制"路线全部否掉了（线框示意图 / 真实空间照+人形标记 / 强制声明），而且第三轮那条修复本身还有害。**
多人（2/3/4）+ 换机位的考试成绩反而是**正面**的：文字把位置、身份、人数基本控住了，跨机位镜像也正确 —— **前提是换机位时给了那个方向的场景参考图**。
真正剩下的、需要做的是两件声明/核查层的事：**换机位换场景参考**、**多余的人/物核查**。

| 轮次 | 测什么 | 结果 | 判定 |
|---|---|---|---|
| pilot-01 | 线框示意图当参考图（3 人同框 + 反打，**反打没换参考图**） | g1 −33.5%（刚过线）、**g2 −3.8%（失效）** | ❌ |
| pilot-02 | 真实空间照 + 人形标记（单人 6 地标） | 出人率 **83%→67%**，出现"幽灵人" | ❌ **净负收益** |
| pilot-03 | **正面强制的"必须有人"声明**（单变量） | 出人率 **83%→67%**，且**在原本 100% 成功的位置上制造了新的空场景** | ❌ **有害** |
| **pilot-04** | **多人 2/3/4 × 机位 正面/反打**（反打**换用**全景 yaw=180 现裁的场景参考） | 出人率 **100%**、位置命中 **11/12**、人数一致 83%；**跨机位镜像正确** | ✅ **正面** |
| **pilot-05** | **视频层**：一镜到底（镜头固定，人走到指定位置）· **i2v vs fl2v** | 落点波动 **0.089 → 0.001**、更贴声明落幅；**取景漂移 p90 21–55.5 → 19–28.5**；出人率 0.92 → **1.00** | ✅ **正面：fl2v 该启用** |
| **pilot-06** | **视频层 · 复杂运镜**（推镜 / 环绕 40°，人不动只让镜头动）· i2v vs fl2v | **相邻帧差中位 13–23 → 2.8–10.4**；环绕档 **19–23 → 2.8–3.7**（低于固定机位基线 4.0）；背景 p90 **79.5–94.5 → 28.5–29** | ✅ **最强正面：fl2v 在复杂运镜上决定成败** |
| 成片审计 | 我们已交付两部片的 32 张关键帧 | **出人率 100%，0 次漏人** | ✅ 常规镜头无此问题 |

## pilot-04：多人 × 机位（本轮最重要的正面结果）

设计：2/3/4 人同一套世界站位，分别用**正面机位**（场景参考=主图）与**反打机位**（场景参考=**从全景 yaw=180 现裁**的空场景照）拍摄。
反打按物理关系**纵深整体反转 + 左右镜像**（正面机位在床尾侧 → 床头的人在反打里变近）。

| 镜 | 人数(声明/检出) | 出人率 | 命中率 | set\|Δu\| |
|---|---|---|---|---|
| m2_front | 2 / 2.5 | 100% | 100% | 0.025 |
| m2_rev | 2 / 2 | 100% | 100% | 0.038 |
| m3_front | 3 / 3 | 100% | 100% | 0.045 |
| m3_rev | 3 / 3 | 100% | 100% | 0.036 |
| m4_front | 4 / 4 | 100% | 100% | 0.048 |
| m4_rev | 4 / 4.5 | 100% | 50% | 0.059 |
| **合计** | — | **100%** | **92%（11/12）** | — |

人眼核对（这是关键，因为 `set|Δu|` 不看身份）：

- **m4_front**：皇帝在左(0.15✓)、苏糖站床尾**背对镜头**(0.30✓)、苏鸾**坐床头**居中(0.54✓)、锦绣在右(0.86✓)。
  → **四个人的身份、位置、前后层次全对**（苏糖最近、苏鸾最远）。
- **m4_rev**：苏鸾变**前景背对镜头**(0.60✓)、锦绣到**左**(0.16✓)、皇帝到**右**(0.86✓)、苏糖变远(0.66✓)。
  → **同一批人的左右与纵深全部按物理正确镜像** —— 跨机位方位守恒成立。
  唯一缺陷：多出一个第 5 人（`extra=1`），`order_ok=false` 是它带出的度量假象。

**三条可复现的结论：**
1. **误差随人数单调上升**：2 人 0.025–0.038 → 3 人 0.036–0.045 → 4 人 0.048–0.072。
2. **反打不再退化，前提是换机位时换场景参考图**：pilot-01 反打（没换参考）= 0.101（是正面 0.051 的两倍）；pilot-04 反打（换了全景 yaw=180）= 0.036–0.059，与正面同量级。
   ⚠️ 诚实说明：两轮的场景/人物不同，这**不是严格 A/B**，但方向一致且有机制解释（`@pano:<yaw>` 那条）。
3. **"多余的人"仍在**：人数一致率 83%（m2_front t2、m4_rev t1 各多一人）。与 desk_quake 复盘里的"第二只杯子"、pilot-01 的多余人物同族 —— **提示词压不住，只能核查**。


## pilot-03：提示词加码失败（这轮否掉的是我自己的修复）

基线臂复跑一遍，**与 pilot-02 逐格一致**（同 seed）——说明指标是稳定的，p3 的失败可复现。

| 位置 | 基线出人率/命中 | 强制声明臂出人率/命中 |
|---|---|---|
| p1 最左衣柜前 | 100% / 100% | 100% / 100% |
| p2 挂轴下几边 | 100% / 100% | **50% / 50%（新失败）** |
| **p3 床上头（远景·坐姿·纱帐内）** | **0% / 0%** | **0% / 0%（照旧）** |
| p4 床尾 | 100% / 100% | 100% / 100% |
| p5 右侧门口 | 100% / 100% | **50% / 50%（新失败）** |
| p6 右侧长柜前 | 100% / 100% | 100% / 100% |
| **合计** | **83% / 10-12** | **67% / 8-12** |

人眼确认：p3 强制声明臂两次都是**配图完美、画面里没有她**；p2 那次同样是一间空屋子。

**两个可复现的结论：**
1. **提示词里加"最高优先级/绝对不允许"这类强调句，会让出人率下降**（83%→67%），并在原本稳定成功的位置上制造新失败 —— 与"长强调句稀释注意力"一致。**不要再往提示词加码。**
2. **p3（坐在床头上·纱帐内·远景）是文字通道结构性做不到的位置**：三轮共 **0/6**（基线 ×4、强制 ×2）。只有 pilot-02 的标记图做到过 2/2 —— 说明"难位置"确实需要非文字手段，但那种手段必须先解决幽灵人副作用。

## 度量层面：这轮发现并修掉的三个坑

1. **`|Δu|` 单独匹配会吃掉"身份互换"**（pilot-01）→ 加 `set|Δu|`（不看身份、排序单调配对）为主指标 + `match_margin`/`ambiguous` 标记。
2. **`order_ok` 继承同一匹配** → 降级为参考，前后序必须人眼看。
3. **"完全没检出主体"被排除在命中率分母之外** → 漏人被静默忽略。已改为**计入未命中**，并把**出人率（presence）提为一等指标**。

## pilot-05：视频层 —— 一镜到底，i2v vs fl2v（**第一个被证实的机制**）

**为什么补这一层**：前四轮量的都是"静态关键帧里人在哪"，而业界点名的头号翻车场景是**运动过程**（"走着走着背景突然变异"、落点不到）。
详见 [`FAILURE-MODES.md`](./FAILURE-MODES.md)。所以这一轮：**镜头完全固定不动**（背景只要变就是真失败），只让人从床尾走到指定位置，比较：

- **i2v**：只给首帧（我们的现状）
- **fl2v**：首帧 + **落幅**（`cli/unit.mjs` 里那条 `--last-keyframe`，全仓库此前没人调用）

| 臂 | 镜 | 出人率 | 末帧 u | 实际 drift | 期望 drift | 背景中位 | 背景 p90 | 背景均值 |
|---|---|---|---|---|---|---|---|---|
| i2v | w1 向左 | 0.92 | 0.154 | −0.319 | −0.29 | 6.0 | 35.0 | 13.2 |
| i2v | w1 向左 | 0.92 | 0.164 | −0.311 | −0.29 | 3.0 | 21.0 | 8.4 |
| **fl2v** | w1 向左 | **1.00** | 0.185 | **−0.288** | −0.29 | 4.0 | 28.5 | 9.7 |
| **fl2v** | w1 向左 | **1.00** | 0.191 | **−0.285** | −0.29 | 3.0 | 27.0 | 9.0 |
| i2v | w2 向右 | 1.00 | 0.691 | **+0.209** | +0.34 | 5.5 | 35.5 | 12.5 |
| i2v | w2 向右 | 1.00 | 0.779 | +0.298 | +0.34 | 10.5 | **55.5** | 20.4 |
| **fl2v** | w2 向右 | 1.00 | **0.771** | **+0.289** | +0.34 | 3.0 | **19.0** | 6.5 |
| **fl2v** | w2 向右 | 1.00 | **0.772** | **+0.290** | +0.34 | 3.0 | **21.5** | 7.9 |

**三条结论：**
1. **落点稳定性**：同一镜两次之间的 drift 波动，i2v 是 **0.089**（0.209 vs 0.298），fl2v 是 **0.001**；且 fl2v 更贴声明的落幅（w1：−0.288/−0.285 vs 期望 −0.29）。
2. **取景/背景稳定性**：i2v 的背景漂移 p90 达 **35.5 / 55.5**（均值 12.5 / 20.4），fl2v 只有 **19.0 / 21.5**（均值 6.5 / 7.9）。
3. **出人率**：i2v 在 w1 是 0.92（有采样帧检不到人），fl2v 是 1.00。

→ **fl2v 该启用**。理由不是"防止背景变异"，而是**落点可控 + 显著降低抽卡波动**；代价是每镜多画一张落幅关键帧（一次生成）。
这也正补上 desk_quake 复盘里的历史欠账「结尾没走到 `end_state`」——当时只用提示词补，而落幅是**机制性**解法。

**边界（不要过度解读）**：n=2/格、单场景、单主体、**镜头固定**。
业界的"背景突然变异"更可能出现在**有镜头运动**时——我们那条带镜头运动的现成成片，背景中位差就是 **34.5**（比本实验高一个量级），而**镜头运动这一档这轮没测**。

### 本轮修掉的一个度量缺陷

`bg_change` 原本只用**中位数** → 对"取景漂移/局部几何位移"不敏感（肉眼能看到衣柜消失，指数却只有 3）。
已改为同时报 **中位数 / p90 / 均值**，并用它**只重跑探针**（不重新生成）复核了全部 8 段——上表即为复核后数据。

## pilot-06：复杂运镜（业界说白模最值钱的那一档）

设计：**人物原地不动，只让镜头动**。两镜 = 推镜（`c1_push_in`）、绕她向左环绕 40°（`c2_orbit`）；两臂仍是 i2v vs fl2v。
度量升级：加了**时间连续性**——**相邻帧差**（中位/p90/最大）。有镜头运动时"与首帧比"天然很大，**只有相邻帧的尖峰才代表模型把画面重画了**。
固定机位那批的基线：相邻帧差中位 **4.0**。

| 镜 | 臂 | 出人率 | drift | 相邻帧差中位 | 相邻帧差最大 | 主体跳跃 | 背景 p90 |
|---|---|---|---|---|---|---|---|
| c1 推镜 | i2v | 1.0 | −0.013 / −0.004 | **13.4 / 15.1** | 14.5 / 19.0 | 0.005 / 0.004 | **83.9 / 87.5** |
| c1 推镜 | **fl2v** | 1.0 | +0.028 / +0.030 | **9.1 / 10.4** | 19.2 / 17.9 | 0.017 / 0.013 | **65.0 / 67.0** |
| c2 环绕 | i2v | 1.0 | −0.060 / −0.030 | **19.1 / 22.7** | 23.5 / **30.4** | 0.007 / 0.005 | **79.5 / 94.5** |
| c2 环绕 | **fl2v** | 1.0 | −0.021 / −0.021 | **3.7 / 2.8** | 8.2 / 7.1 | 0.035 / 0.011 | **28.5 / 29.0** |

**人眼核对（c2 环绕那对，最差 vs 最好）**：
- **i2v**：t=0 正面（床在左、柜在右）→ t=0.84 换了一间屋 → t=2.08 又换 → t=2.92 冒出新的窗 → t=3.96 冒出新的门洞 → t=5.0 再换一次。**每秒都在重新发明这间屋子**，而她本人稳稳在画面中央（u 0.44–0.47）✗✗✗ —— 这就是业界说的"空间关系错乱 / 背景突然变异"。
- **fl2v**：同一间屋子从正面平滑转到她的左前方，六帧空间连续、无跳变，她逐步转成三分之四侧身 ✓✓✓

**结论：**
1. **复杂运镜正是翻车现场**：i2v 在推镜/环绕下的相邻帧差是固定机位基线的 **3–6 倍**（19–23 vs 4.0）。
2. **fl2v 在环绕档把它压到基线以下**（2.8–3.7），背景 p90 从 79.5–94.5 降到 28.5–29（**约 1/3**）。
3. **推镜档改善较小**（13–15 → 9–10，背景 84–88 → 65–67）：说明 fl2v 的收益**主要来自"需要几何一致的旋转/换视角"，而不是单纯的缩放**。
4. 出人率全程 1.0；主体屏幕位置全程稳定（`du_max` ≤0.035）—— **翻的不是人，是世界**。

**边界**：n=2/格、单场景、单主体；落幅关键帧由图像模型生成（本轮效果可用，未见明显画错）。

## 对方案的影响（净结果：方案变小了，不是变大了）

| 项 | 处置 | 依据 |
|---|---|---|
| 线框示意图 / 真实空间照+人形标记 / 提示词强调句 | ❌ **全部砍掉** | pilot-01/02/03 |
| 自建白模渲染器、3DGS、全景机位截图（作为"位置控制"） | ❌ **不做** | 位置不是痛点：单人 10/10、多人 11/12 命中 |
| **换机位 → 换那个方向的场景参考图** | ✅ **优先做** | pilot-01 反打 0.101（没换参考） vs pilot-04 反打 0.036–0.059（换成全景 yaw=180 现裁） |
| **"多余的人/物"核查**（检出人数 ≠ 声明人数 → 告警） | ✅ **做** | 人数一致率 83%；desk_quake"第二只杯子"、pilot-01 与 pilot-04 的多余人物 |
| **fl2v（首帧 + 落幅）启用** | ✅ **最高优先** | pilot-05 落点波动 0.089→0.001；**pilot-06 复杂运镜相邻帧差 19–23→2.8–3.7、背景 p90 79.5–94.5→28.5–29**。补上 desk_quake「没走到 end_state」那条欠账 |
| 镜头运动档的验证（推拉/环绕） | ✅ **已测（pilot-06）** | 结论：**这档必须用 fl2v**；推镜收益小、环绕收益大 |
| **主体存在性核查**（生成后判"画里有没有人"） | ✅ 做（低成本兜底） | 三种祈祷式手段都失败；检测器在 32 张真实成片上 100% 可用 |
| **导演稿规则：不要给主体叠加"远景+坐姿+遮挡"三重不利条件** | ✅ 做 | p3 结构性不可达（0/6），重抽也救不回来 |
| 轴/机位侧声明（越轴核查） | ⚠️ **降级**：先做"换机位换参考"，越轴 lint 可后置 | pilot-04 显示给对参考后跨机位镜像自然正确 |
| ControlNet 硬控制 | ❌ 不投 | 四轮实验一致表明位置不是痛点 |
