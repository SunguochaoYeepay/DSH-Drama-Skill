# 剧本工艺

写新剧本或修改已确认剧本之前读取本文件。本文件只拥有"写什么、怎么讲好"的工艺；
格式与保真归 `src/parse-script.mjs`（台词逐字搬运是构造保证），登记与票据归
`references/workflow.md`，不在此重复。

> 剧本阶段默认由当前对话的 Agent 直写（`cli/script.mjs register-agent`）。
> 本文件是直写时唯一的工艺依据：**格式有解析器兜底，讲好故事没有兜底。**

## 一、总原则

1. `story.md` 是**给人看的拍摄底稿**，不是给模型的提示词。景别、镜头、参考图等技术字段一个都不写在这里——那是下游的活。
2. **结构先于文字。** 先想清楚节拍，再写台词和动作。字句可以在对话里随手改，结构散了整片就散了。
3. 短剧观众**随时划走**。每个工艺决定都用同一把尺量：这一拍能不能让人多看三秒。

## 二、短剧节拍结构（60–90 秒版）

完整短剧的最小节拍骨架：

| 拍位 | 功能 | 时长体感 | 拍好的标准 |
|---|---|---|---|
| 钩子 | 前 3 秒留住人 | 1–3 秒 | 不看剧情介绍就想知道"然后呢" |
| 建立 | 交代谁、在哪、要什么 | ≤10 秒 | 观众能说出主角此刻想要什么 |
| 升级 | 阻碍出现并加压 | 主体时长 | 每一拍都比上一拍更紧 |
| 反转 | 意料之外、情理之中 | 独立成拍 | 回头看处处有伏笔 |
| 落点 | 情绪兑现 | 1–2 拍 | 观众在这里产生"值了"的感觉 |
| 定格 | 结尾落地 | 最后 3–5 秒 | 画面能停在一张关键帧上 |

硬规则：

1. **反转必须独立成拍。** 反转和别的内容挤在同一拍，情绪被稀释，AI 生成时也会和相邻内容互相污染。
2. **每拍都要能回答"为什么必须在片子里"。** 答不上来的拍，删掉。`purpose` 决定下游用什么镜头语言去拍——没有 purpose 的节拍，拍出来只能是一张插图。
3. **结尾必须落地。** "他走了"不是落地；"他走出球场回头看了一眼，晚霞压在地平线上，没有回头第二次"才是。没有落点的故事，下游必然生成一堆烂尾镜头。
4. 拍数服从故事，不服从公式。6 拍能讲完不要凑 10 拍。

## 三、人物动机最小集

每个主要角色，在他出场的每场戏里，剧本要让导演能答出三问：

1. **想要什么**——这场戏里他的目标（赔到钱、藏住秘密、把话说出口）。
2. **知道什么**——此刻他掌握的信息（他不知道的事，是他动作迟疑的原因）。
3. **怕什么**——stakes，输掉会怎样。

这三问是下游的燃料：导演的情绪因果链要求 `cause → internal_state → visible_behavior`，
`cause` 只能引用"已发生的剧情事实"。**剧本没写清动机，导演的 cause 就没有事实可引，
情绪分析就成了编词。** 这是剧本工艺和导演工艺之间的供料契约。

检验：任选一个出场角色、任选一个他行动的时刻，说不出这三问，回到剧本补。

## 四、台词工艺

1. **时长先算后写。** 中文台词默认 4–5 字/秒，单句超过 60 字就要拆或砍——15 秒是单次生成的硬上限，写超了导演只能在"裁台词"和"砍动作"之间两难。`parse-script` 抠出的台词会被逐字念出，没人能替你缩。
2. **一句话只干一件事。** 信息密度高的台词留给情绪平的拍；情绪重的拍，台词要短。
3. **括号提示只写摄像机看得见的。** "压低声音""攥紧袖口"是导演可用的信号；"心里一酸"不是。行格式须兼容 `src/parse-script.mjs` 的台词正则。
4. **已确认剧本台词一字不改**（SKILL.md 的底线）。所以写的时候就要把每一句打磨到值得被逐字念出——笑点长在措辞里，改一个字就没了。

## 五、分题材节奏注记

通用骨架不变，节奏重心随题材换：

- **真人情感剧**（realistic 系）：钩子多用悬念/冲突（一句话擦出火药味）；表演靠克制；升级拍之间留呼吸（沉默也是内容）；落点常落在"没说完的那半句"。
- **3D 卡通剧**（cartoon3d）：钩子多用视觉奇观或反差萌；节奏可以更快更密；反转可以靠夸张肢体；落点常定格在一个 pose。
- **悬疑向**：升级拍要让观众比角色少知道一点（withhold）；反转前的最后一拍故意给足日常感。

题材专属的**视觉语言**（摄影/渲染/调色词汇）不在本文件，在
`references/art/<style>.md` 风格包里；本文件只管叙事。

## 六、剧本自检清单（送审前自跑）

1. 前 3 秒，观众有理由不划走吗？钩子是哪种？
2. 每一拍都能一句话说出 purpose 吗？
3. 反转独立成拍了吗？前面有伏笔吗？
4. 结尾落地了吗？最后一幕能用一张静态画面定格吗？
5. 每个主要角色、每场戏，"想要什么/知道什么/怕什么"答得出来吗？
6. 哪句台词按 4–5 字/秒念不完？
7. 反复出现的物件（信物、道具、告示）在剧本里标出来了吗？——它们是要立项成资产的。
8. 用 3–5 句话能讲完全片（含转折和结尾）吗？讲不全就是结构没定。
