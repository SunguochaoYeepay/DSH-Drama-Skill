# 生图词汇库（抽卡师弹药）

**归属：抽卡师。** 写提示词时的正向词汇参考——`prompt-rules.md` 管"不能怎么写"，
本文件管"怎么写得更好"。词汇吸收自业内 2000+ 条实测提示词语料
（awesome-gpt-image-2，CC BY 4.0，2026-09-21 摘录），按我们的通道筛过一遍。

## 用法三条

1. **词是弹药，不是模板**。按画面需要挑，不是每条都塞；挑中的词要跟导演的光线/机位意图一致，
   不一致时以导演稿为准。
2. **中文直写**。我们的通道是 Qwen 中文编码器，下列词均已转写为可直接进提示词的中文；
   原英文词附在括号里仅供查源，**不要把英文混进提示词**（中英混排效果从未对照验证，别开这个口子）。
3. **负面词表不收**。语料里的 Negative Prompt 是写给指令跟随型模型（GPT Image 系）的；
   我们的扩散通道里正向写负面实体=负例词中毒（两次阴性实验的教训）。禁令只有实测三件套
   （参考图职责/身份锚/禁字行），别的负面词一律不写。

## 一、光照（什么时候用：光线行）

按**氛围意图**选，一条光线行最多叠两三个词，多则互相稀释：

| 意图 | 可直写词 |
|---|---|
| 自然日常 | 都市白天自然光、柔和漫射光、树影把阳光筛成斑驳光影、窗边侧光 |
| 黄金时刻 | 傍晚黄金时刻的暖光（golden hour）、低角度暖阳、暖橙色调染满场景 |
| 戏剧张力 | 单一暖光源侧照、明暗对照强烈（chiaroscuro）、大半张脸没入深色阴影、轮廓边缘光（rim light）勾出剪影 |
| 夜景 | 路灯暖黄光池、霓虹反光落在湿地面、冷蓝夜色里一点暖窗光 |
| 柔美 | 逆光光晕（backlight halo）、发丝边缘透光、柔光罩般的均匀光 |

**写光要写落点**：光打在哪（脸侧/发丝/地面）、形成什么（斑驳影子/长影/光晕）。
只写光源不写落点，模型自己乱分配。

## 二、镜头与构图（什么时候用：景别句与机位语义）

| 意图 | 可直写词 |
|---|---|
| 人像质感 | 浅景深背景虚化成柔和色块、85mm 人像镜头视角、背景奶油般化开 |
| 纪实感 | 手持跟拍的轻微晃动、抓拍瞬间感、画面轻微倾斜 |
| 气势 | 极低机位仰拍、主体在画面里高耸压迫、地面贴地的视角 |
| 空间纵深 | 纵深方向的街道延伸向远处、前景虚化的树干框住主体 |
| 电影感 | 电影级调色、中低饱和、轻微胶片颗粒、变形宽银幕般的横向空间 |

机位角：平视（eye-level）/低角度/高角度俯拍/贴地——跟导演稿的 `camera` 字段一致时才写。

## 三、材质与纹理（什么时候用：主体、服装、地面）

写实档的质感差异全在这层，风格档（anime 等）不写这层：

| 对象 | 可直写词 |
|---|---|
| 皮肤 | 真实皮肤质感、可见毛孔、自然光泽不反光 |
| 布料 | 牛仔布纹理清晰、针织物的线圈肌理、丝绸的垂坠与哑光、皮革的自然反光 |
| 丝袜 | 丝袜的半透质感与轻微光泽（写实档黑丝必写，防画成实心裤） |
| 地面 | 灰色人行道砖的砖缝、柏油路的粗颗粒、湿润路面的镜面反光 |
| 磨损 | 边角磨白的旧包、砖面的风化坑洼、金属扶手的划痕（限定强度，别堆） |

## 四、姿态与动作几何（什么时候用：keyframe_start 转译）

**这是 LLM 抽卡师最该发力的一层**——导演写速度/情绪/状态，你画几何：

| 导演会说 | 几何化转译 |
|---|---|
| 走得快/急匆匆 | 前脚脚跟着地、后脚脚尖点地脚跟抬起、步幅大、手臂摆幅大 |
| 慢悠悠地走 | 双脚全掌落地、步幅小、重心居中、手插口袋 |
| 没看路/发呆 | 眼神放空望向前方半空、头部微偏、目光不聚焦在近处物体上 |
| 警觉/注意到什么 | 头部转向声源、肩膀绷紧、目光聚焦锁定一点 |
| 靠着什么 | 肩胛贴墙面、一条腿承重另一条腿脚尖点地交叉、重心偏移 |
| 蹲下捡东西 | 单膝弯曲下蹲、手臂前伸手指张开朝向地面物体、背部前倾 |

**手部必须给明确任务**（拿手机/扶栏杆/插口袋），不给任务的手最容易被画坏。
**接触点必须写**（脚踩在哪/手扶什么/臀部落在哪）——接触点缺失=悬空事故的根源。

## 五、通道警示（用词前先过这三关）

1. **负面词不进正向**（见用法 3）。
2. **图生图为主**：语料是纯文生图场景的词，"preserving facial identity"这类身份语句
   在我们通道里由参考图职责行承担，不要照搬英文句式。
3. **词汇密度服从字数预算**：全部词汇加起来仍受 `prompt-rules.md` 500 字上限约束，
   每句挑最能区分画面的 1–2 个词，宁可少而准。
