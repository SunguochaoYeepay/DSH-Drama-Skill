# 动作戏工艺

剧本里要写打斗、追逐、对峙或任何"身体冲突"的戏之前读本文件。总原则、节拍骨架和
台词工艺归 `references/story-craft.md`；本文件只拥有"动作怎么写才不瞬移、不穿模、有打击感"。

> 工艺来源：导演技能包 action-fight-prompt（github.com/kangarooking/director-skills，MIT），
> 已按生成流水线改造——时序拆段对齐我们的单元切镜结构，群战与特效全部过生成成本筛。

## 一、为什么动作戏要单独一套

动作戏的两大废片根源，都不是"画得不好"，是**写得不好**：

1. **瞬移**：剧本写"他冲过去一拳打倒对方"，中间过程一个字没写。模型在动作段边界处
   只能自己脑补位移——首帧在门口、尾帧已挥拳，中间就是瞬移。
2. **穿模**：两个动作之间没有因果衔接，模型把两段独立渲染再硬接，武器穿过身体、
   手臂穿过桌角都这么来的。

根因同一个：**孤立动作**。修法不是抽卡赌，是把动作链写完整。

## 二、时序拆段（动作戏的地基）

单元内的动作戏按 **2–3 秒一段**拆，每段只管一组主动作：

- 一个动作段 = 一个 `[Shot N]`（导演稿切镜），切点就是段边界——我们的单元切镜结构
  与这套拆段法**天然对齐**，导演照常写 shot，只是动作戏的 shot 必须服从 2–3 秒节奏。
- 每段一句话回答"这段谁在动、做什么动作、落点在哪"。
- 15 秒单元 ≈ 5–7 个动作段；动作戏宁可拆成两个单元，不要在一个单元里塞三组交锋。

**生成账单**：H3 单次生成 15 秒硬上限；动作段越密，段间"脑补位移"越多，抽卡成本
按段数平方涨。

## 三、动作因果链（防瞬移穿模的核心）

**相邻两个动作之间，必须能读出"因为 A，所以 B"。**

写法检验：把动作段首尾相连读一遍，任何一处"为什么他现在在这儿"答不出来，就是断链，
补上衔接动作（挪步、转身、抬手格挡）再往下写。

好例（每步都是上一步的物理后果）：

> 对手前倾扑来 → 他顺势下沉抓肩 → 借对方前倾的重量别腿 → 对手失衡前扑 → 他侧身让位，对手撞上桌角

坏例（孤立动作，模型只能瞎接）：

> 他抓住对手 → 对手倒地 → 他赢了

## 四、一场交锋怎么拆成镜头序列（编舞）

第三节目的是"镜头内部不乱"，本节目的是"**镜头之间不塌**"——一场交锋不是一句
"两人打了起来"，是一个攻守交替的镜头序列（2026-09-21 吸收自 AIComicBuilder 的
shot_split 战斗强制规则，Apache 2.0，已按单集体量压缩）：

1. **一招至少 4–6 个镜头。** 基准序列：A 蓄力 → B 格挡/闪避 → 碰撞冲击 → B 反击 →
   A 受创/稳住 → 拉远全景交代位置。少于 4 个镜头的"一招"，模型只能自己脑补中间过程——
   脑补的部分就是瞬移和穿模。
2. **攻守必须交替，双方都要有主动攻击镜头。** 全程只有 A 出招、B 挨打，或者 B 只靠
   "抬手镇压"化解一切，交锋就不成立——观众读不出"谁在赢"。写每一招时点名：这一组
   镜头里谁攻谁守，下一组换不换。
3. **精神空间 / 顿悟 / 回忆镜头 ≤ 战斗镜头的 30%。** "他在心中默念口诀，周身金光暴涨"
   这类镜头便宜又安全，但堆多了动作戏就泄气——它是调味，不是主菜。
4. **镜头序列服从前两节**：每个镜头仍是 2–3 秒一个动作段（第二节），相邻镜头的衔接
   仍要过"因为 A 所以 B"检验（第三节）——编舞管的是"该有哪些镜头"，不管怎么豁免工艺。

**生成账单**：4–6 镜头 ≈ 一个满 15 秒单元。一场交锋拆不完时**拆成两个单元**
（在稳定状态处切，见 `directing.md`），不要硬压镜头数——压掉的不是时长，是因果链。

## 五、打击感四环

有身体接触的动作，每个打击按四环写全。缺任何一环，打击就是"贴上去"而不是"打进去"：

1. **力量来源**：腰部拧转、蹬地、重心前移——打击不是手臂独立完成的。
2. **接触瞬间**：材质词写具体——拳锋接触颧骨的闷响、刀刃刮过金属的锐鸣、迸出的火星。
3. **物理后果**：被打者偏转半寸、后退踉跄、护甲凹陷——**后果恰好为下一动作提供
   因果条件**（踉跄露出破绽 → 下一击顺势而至）。这环连着第三节，不能断。
4. **环境反馈**：按地表材质给词——沙地被蹬出犁沟、木地板震颤、混凝土崩出碎屑。
   环境没反应的打击，观众身体不信。

**硬碰硬四步**（实力差戏的精髓）：全力一击 → 火花巨响 → **明确失败**（"刀锋停在甲面上，
没有切入、没有伤痕"）→ 反作用力把持刀者震得虎口发麻、连退两步。**禁写"砍进去了"**——
第一击必须失败且物理一致，实力差才立得住；写进去了，后面就没法圆回来。

## 六、运镜与节奏（写给导演稿的供料）

剧本不写运镜（总原则），但节拍要给导演留出运镜空间——动作戏的节奏结构：

- **蓄力段**：慢——留缓推、低角度、呼吸声的空间。
- **爆发段**：快——贴身跟拍、手持震动。爆发段 ≤ 3 秒，长了模型维持不住动作连贯。
- **慢动作**：每段最多一次，且**给具体时长**（"0.2–0.3 秒的慢动作：拳锋压扁对方脸颊"）。
  写"慢镜头拍这一下"而不给时长，模型会随机选一段拉长，节奏必乱。

## 六、生成友好硬约束（动作戏特有的）

1. **群战是奢侈品中的奢侈品。** 原方法论"群战对手面孔各不相同"对我们是灾难——
   同框人脸超过 3 个必糊。降级路径：群战 → 2v1 → 1v1；"被围殴"改成"两名打手先后上前，
   其余人在背景虚化处站定"。
2. **武器与护甲先立项。** 刀、棍、甲、枪械都是道具资产——没立项的武器每镜长得不一样。
   打击特效词（火星、碎屑、崩裂）写具体材质，不写"特效炸裂"这类空词。
3. **动作段台词另算预算。** 边打边说比站着说更慢，动作段内台词按 **3 字/秒**做预算，
   且一句台词只跨一个动作段——台词横跨切镜点，口型和动作两头都容易崩。
4. **打完的账要记进造型。** 打斗后的衣衫破损、伤口、灰尘是**状态**不是造型——按
   `assets-and-keyframes.md` 的规则，写进 `keyframe_start` 与镜头动作，或单独立一个
   "战后造型" identity，不塞进干净造型描述里。
5. **追逐戏先数空间账。** 载具追逐每换一个地点就是一个新场景资产；单集追逐控制在
   1–2 个空间内，用机位和景别变化换速度感，不靠换场景。

## 七、动作戏自检（送审前自跑，人工判断不评分）

1. 把动作段首尾相连读一遍：有没有哪一步"他为什么现在在这儿"答不出来？
2. 每个打击四环全吗？物理后果是不是恰好引出下一动作？
3. 实力差戏的第一击，写明确失败了吗？有没有偷写"砍进去了"？
4. 慢动作每段 ≤ 1 次且给了具体时长吗？
5. 同框人脸最多几个？武器立项了吗？战后状态放对层了吗？
