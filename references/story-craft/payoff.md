# 落点与爽感设计

写剧本的落点拍、定格拍之前读本文件。总原则和节拍骨架归 `references/story-craft.md`；
钩子类型学归 `hooks.md`；本文件只拥有"情绪兑现（爽感）怎么设计"。

> 工艺来源：商业化微短剧编剧方法论（github.com/0xsline/short-drama，MIT），已按生成流水线改造。

## 一、核心公式：压抑 → 释放

**爽感的本质是压抑的释放。压抑越深，释放越爽；没有压抑的爽是廉价的。**

落到我们的节拍骨架：

```text
升级拍 = 压抑蓄力（每一拍比上一拍更紧，就是在攒"欠观众的"）
落点拍 = 释放兑现（把攒的全还回去）
定格拍 = 释放后的余韵画面（情绪兑现在这一帧上落地）
```

推论：**压抑不够时砍爽点，不砍压抑。** 60–90 秒的单集装一个大爽点（落点拍独占），
前面压抑铺垫不足就简化爽点场面，不要硬放。

## 二、五大爽点类型

| 型 | 一句话 | 情绪公式 | 适用 |
|---|---|---|---|
| 身份碾压 | 被看不起的人亮出真实身份 | 轻视侮辱 → 蓄力 → 揭露 → 碾压 | 战神、霸总、萌宝 |
| 打脸复仇 | 恶人搬起石头砸自己的脚 | 被欺负 → 隐忍 → 反击 → 当众出丑 | 全题材通用 |
| 逆袭翻盘 | 从谷底绝地反弹 | 谷底 → 绝望 → 转机 → 翻盘 | 逆袭、重生、悬疑 |
| 情感爆发 | 压抑已久的情感突然释放 | 误会压抑 → 积累到极限 → 爆发/告白/和解 | 甜宠、霸总、家庭 |
| 悬念揭秘 | 困扰已久的谜题揭晓 | 谜题 → 线索 → 逼近 → 揭秘 | 悬疑、重生、宫廷 |

各型要点：

1. **身份碾压**：揭露方式要有仪式感；施辱者下场要交代（跪地/被开除/煞白）。仪式感 = 可拍的画面：揭露拍用同框站位反转——开场谁压谁的构图，在这里倒过来。
2. **打脸复仇**：主角越冷静越爽；打脸方式要出人意料；**旁观者的震惊反应是放大器**（生成注记见下）。打脸后要有余韵（定格拍干这个）。
3. **逆袭翻盘**：谷底必须够低；转机不能突兀（前置伏笔，见 `antagonist.md`）；翻盘要有见证者——降级为 1–2 个具名角色。
4. **情感爆发**：爆发台词要"真"，不要文艺腔；**肢体语言比台词有力量**（这恰好生成友好：动作是摄像机看得见的）；不要连续安排爆发，会稀释。
5. **悬念揭秘**：真相必须出人意料但合情合理（伏笔支撑）；揭秘后必须有角色反应拍；一个大揭秘可以带出新谜题。

## 三、密度与搭配

- **单集**：一个大爽点，落点拍独占。小爽（一句回击、一个眼神糖）可以撒在升级拍里当味精，但不许喧宾夺主。
- **系列**：爽点强度要递增，全剧最强爽点必须放在最后阶段；同类型爽点不连续出现（连打三次脸必疲劳）；情感爽点和力量爽点交替；大爽点前面要有小爽点铺垫。
- **搭配铁律**：爽点被立刻推翻 = 观众觉得被耍。落点拍兑现的东西，不许在定格拍又收回去。

## 四、生成友好硬约束（爽点特有的）

1. **旁观者放大器降级。** "全场震惊/鸦雀无声/众人议论"是群演场面，H3 画不住。改写成 1–2 个具名角色的具体反应（势利同事的脸、对手松手的号码牌）。
2. **屏幕揭露是陷阱。** "大屏幕亮起转账记录""手机弹出转账通知"——屏幕上的文字是中文渲染，H3 烧字不稳定。改用实物道具：U 盘、印章、签了名的合同页、拍立得照片。道具先立项。
3. **碾压场面数人头。** 身份碾压的"全场/全公司/全网见证"逐级缩水：单集 2–3 人同框封顶。见证者数量不够时，用受辱与揭露的**构图对倒**补足爽感。
4. **爆发的落点在脸上和手上。** 情感爆发写"眼眶通红""手在抖"，不写"心碎了"——前者是关键帧能画的，后者是导演编不出来也画不出的。

## 五、爽点自检（送审前自跑，人工判断不评分）

1. 落点拍之前，压抑攒够了吗？（能说出"欠观众什么"吗）
2. 释放彻底吗？攒的情绪有没有全还回去？
3. 有具名角色的反应拍吗（不是"全场哗然"）？
4. 施害者/施辱者的下场交代了吗？
5. 爽点场面里有几个同框人脸？超过 3 个就重排。
6. 揭露靠的是实物道具还是屏幕文字？屏幕文字改道具。
