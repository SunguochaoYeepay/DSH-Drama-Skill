# 对抗与伏笔设计

写剧本的对抗关系（反派）和伏笔之前读本文件。主角动机三问归 `references/story-craft.md`；
本文件只拥有"对手怎么设计、伏笔怎么埋"。

> 工艺来源：商业化微短剧编剧方法论（github.com/0xsline/short-drama，MIT），已按生成流水线改造。
> 原体系的四层反派面向 40–100 集连续剧；我们按单集 60–90 秒和系列剧分档压缩。

## 一、反派三问（并入动机最小集）

主角有动机三问（想要什么/知道什么/怕什么），**每个有名字的对手角色同样要答出三问**：

1. **他为什么要做坏事？**（动机）——利益驱动 / 嫉妒 / 恐惧 / 偏执 / 立场不同。答不出的反派是纸片，观众不恨也不信。
2. **他的能力从哪来？**（支撑）——权力 / 财富 / 人脉 / 情报 / 特殊能力。支撑要与压迫感匹配。
3. **他为什么不更早、更直接地对付主角？**（节制）——没放在眼里 / 有所顾忌 / 在等时机。答不出这条，剧本就会"反派该动手时不动手"，剧情靠反派降智推进。

可恨的手法（选 1–2 种，别全用）：欺负弱者、恩将仇报、当众羞辱、背后使刀、夺人所爱、
嚣张跋扈。**"让反派可恨"的所有手段里，只选摄像机拍得出来的。**

## 二、层级分档

原方法论四层：小反派（炮灰）→ 中反派（主要对手）→ 大反派（终极 Boss）→ 隐藏反派（终极反转）。
**层级越多，需要的时长越长**——照我们的体量分档：

| 体量 | 可用层级 | 说明 |
|---|---|---|
| 单集 60–90s | **最多 1 层** | 一个对手，一次交锋定胜负。四层体系塞进单集 = 每层都立不住。 |
| 系列（≤10 集） | 2 层 | 小反派开胃 + 一个主要对手；或单个对手走三段式。 |
| 长篇（>10 集） | 3–4 层 | 全套可用；隐藏反派见下节警告。 |

**击败三段式**（系列用；单集压缩成"升级拍受挫 → 反转拍翻盘"两拍）：

```text
第一次交锋：主角小胜或平手（试探）
第二次交锋：对手反击，主角受挫（低谷——压抑蓄力，给落点拍的）
第三次交锋：主角翻盘击败（高潮）
```

对手必须至少赢主角一次——全程被碾压的对手撑不起紧张感，落点拍的释放也没了对象。
每层对手被击败后，下一层要有出场来路（"你以为赢了？我后面还有人"），不能空降。

## 三、伏笔埋设

**反转的冲击力取决于之前建立的"以为"有多稳；反转的合法性取决于可回溯的伏笔有多少。**

画面伏笔 vs 文字伏笔——**只有画面伏笔算数**：

- 画面伏笔：观众看得见的细节（他接了个电话匆匆离开、关键时刻消失又出现、桌上多了一件不该在那的东西）。这一类画得出来，才立得住。
- 文字伏笔：只有台词提到、画面上没有的事。观众记不住，回看也找不到——等于没埋。

埋设模板（反转拍/隐藏反派共用）：

```text
伏笔1（早）：一个小细节，当时看不出问题。
伏笔2（中）：一次可疑行为，但有合理解释（"堵车了"）。
伏笔3（晚）：一个几乎暴露的瞬间，被其他事件岔开。
揭露（反转拍/终局）：所有线索串联，每个"巧合"都指向他。
```

- 单集：反转拍之前**至少 1 处画面伏笔**（60–90 秒埋 3 处会挤死节拍，1 处足矣，但要"回看得见"）。
- 系列：大反转至少 3 处可回溯；隐藏反派的伏笔不能明显到提前穿帮，也不能少到揭露时观众觉得被骗。

隐藏反派警告（原方法论的警告，全盘保留）：不重要的角色不能做隐藏反派（没有情感冲击）；
没有铺垫的反转是败笔；大反派被击败前不揭露隐藏反派（节奏混乱）；动机牵强的"其实我一直恨你"是灾难。

## 四、反派台词分级

对手的台词随层级变风格——写台词时对号入座：

| 层级 | 台词风格 | 例 |
|---|---|---|
| 小反派 | 嚣张直白、看不起人 | "你也配？"（被打脸后：结巴/求饶/面色煞白） |
| 中反派 | 阴险含蓄、威胁利诱 | "你以为赢了？天真。"（被击败后：不甘，暗示更大的势力） |
| 大反派 | 从容自信、高高在上 | "你还不够格。"（被击败后：不服/揭露更多真相） |
| 隐藏反派 | 揭露前温柔可靠；揭露时 180 度反转 | "你真的以为这一切是巧合？" |

台词时长照旧按 4–5 字/秒算——嚣张台词恰恰要短，一句"你也配？"比一段宣言狠。

## 五、对抗自检（送审前自跑，人工判断不评分）

1. 对手的动机三问答出来了吗？尤其"为什么不动手"这条。
2. 对手至少赢了主角一次吗？
3. 单集里对手是不是只有一层？多层的砍掉。
4. 反转拍之前，有"回看得见"的画面伏笔吗？文字伏笔不算。
5. 伏笔道具（那通电话、那张照片、那件东西）立项了吗？
6. 对手台词的风格跟层级匹配吗？字数念得完吗？
