# 钩子与开场类型学

写剧本的钩子拍（开场前 3 秒）和结尾钩之前读本文件。总原则、节拍骨架和台词工艺归
`references/story-craft.md`；本文件只拥有"钩子怎么设计"的类型学。

> 工艺来源：商业化微短剧编剧方法论（github.com/0xsline/short-drama，MIT），已按生成流水线改造——
> 每个模式都补了"第一张关键帧画什么"，并加了生成友好的硬约束。

## 一、两个钩子，别混

| | 钩子拍（开场） | 结尾钩 |
|---|---|---|
| 位置 | 前 1–3 秒 | 最后一拍 |
| 任务 | 让人不划走 | 让人想看下一集 |
| 默认 | 每集必有 | **单集默认不用**，用定格收束；只有明确做成系列（有下一集）才留结尾钩 |

## 二、开场六式（钩子拍的模板）

每式给出结构、"第一张关键帧"（这一拍最终定格成哪张图——写钩子时就要能答出这张图）。

### 1. 直接打脸型

- **结构**：主角被当众羞辱 → 施辱者嚣张至极 → 主角隐忍或微妙反应（暗示身份不简单）。
- **第一张关键帧**：受辱瞬间的中景，主角与施辱者同框、主从构图分明（谁压谁一目了然）。
- **要点**：羞辱越狠，后续打脸越爽——蓄力是给落点拍的，不是白写的。适用：逆袭、家庭伦理、战神。

### 2. 身份反转型

- **结构**：角色 A 对角色 B 的"低评价" → 立刻揭露 B 的真实身份远超想象 → 认知反差。
- **第一张关键帧**：同框两人的地位反差构图（拦人者 vs 鞠躬者），或"脸色骤变"的近景。
- **要点**：落差即爽感来源。生成注记：两人的地位反转要靠构图站位说话，不靠字幕。适用：霸总、萌宝、都市情感。

### 3. 极端困境型

- **结构**：主角处于绝境/死亡边缘 → 不可思议的转折（重生/穿越/觉醒）→ 主角意识到"第二次机会"。
- **第一张关键帧**：绝境特写（血泊中的手）或转折后睁眼的近景。
- **要点**：前世越惨，改写动机越强。**生成账单警告**：两套时空 = 同角色两套妆发服装 + 两个空间，全是资产成本，单集慎用。适用：重生、悬疑。

### 4. 倒叙悬念型

- **结构**：先给高冲击力的结果场景（血案/葬礼/审判）→ 字幕"X 天前" → 回到开端。
- **第一张关键帧**：结果场景里"反常识"的那一拍（满脸伤痕却面带微笑的被告）。
- **要点**：结果必须不可思议，观众才必须知道"怎么会变成这样"。生成注记：倒叙=多一个时空的资产账单，同款警告。适用：悬疑、家庭伦理、古装。

### 5. 高甜钩子型

- **结构**：男女主意外"亲密接触" → 化学反应（对视/心跳）→ 一句让人心跳加速的台词。
- **第一张关键帧**：接触瞬间的双人近景（接腰、四目相对）。
- **要点**：不需要大场面，一个眼神一句话就够；关键是让观众"磕到了"。这是最便宜的开场——2 人、1 个室内空间。适用：甜宠、霸总。

### 6. 重生起始型

- **结构**：直接从重生/回归那一刻开始 → 快速确认现状（时间/地点/身份）→ 立刻展示"金手指"或行动。
- **第一张关键帧**：睁眼特写 + 手机日期屏（或等价的时代锚点道具）。
- **要点**：要快。观众不需要前世全貌，只需要"他知道接下来会发生什么，他开始动了"。日期屏是道具，先立项。适用：重生、末日、战神。

### 开场禁令

- ❌ 大段旁白介绍背景（旁白还是台词，逐字念出来，4–5 字/秒地烧时长）。
- ❌ 慢节奏风景空镜开场。
- ❌ 日常生活流水账；"从前有个人叫 xxx"式平铺直叙。
- ❌ 多角色同时出场（首场 ≤3 人，AI 生成的同框人脸越多越糊）。

## 三、结尾钩五型（仅系列剧用）

钩子公式：**制造一个观众"必须知道答案"的问题，然后不给答案。**

| 型 | 一句话 | 机制 | 精选子模式 |
|---|---|---|---|
| 悬念钩 | 抛出关键疑问，答案留到下一集 | 建立期待 → 接近答案 → 揭晓前切断 | 身份悬念（摘下面具——）、结果悬念（验孕棒第二条线）、发现悬念（打开抽屉瞳孔骤缩） |
| 反转钩 | 最后一秒颠覆观众预期 | 以为 A → 揭示其实是 B → 切断 | 身份反转、关系反转（DNA：父女）、动机反转（"我恨的是我自己"） |
| 情绪钩 | 情绪推到最高点然后切断 | 情感铺垫 → 升温 → 顶峰前切断 | 甜蜜中断（凑近——手机响）、决绝中断（"我们分开吧"）、重逢中断（那个背影……） |
| 信息钩 | 透露关键信息但只说一半 | 发现 → 解读了一部分 → 切断 | 证据揭露、记忆闪回、线索串联 |
| 危机钩 | 突发重大危机，主角来不及反应 | 平静假象 → 危机 → 逼近 → 切断 | 背刺（喝了他递的水——他笑了）、暴露、倒计时 |

各型通用规则：

1. **疑问必须与主线强相关**，不拿无关琐事骗观众；下一集必须回应，回应可以不完整但必须给新信息。
2. **反转必须有前置铺垫**（见 `antagonist.md` 的伏笔埋设）；冲击力取决于之前建立的"以为"有多稳。
3. **情绪钩的铺垫要足够长**，中断方式要自然（不能刻意到像编剧伸手按的）。
4. **危机钩主角必须来不及反应**——反应留给下一集，这一集切断在危险逼近的那一拍。
5. **频率**：连续 3 集不用同型；反转钩全系列不超过 5–7 次，用多则观众免疫。
6. **叠加**：悬念+情绪、反转+危机、信息+悬念可叠加；反转+反转、信息+信息互相稀释，禁止。

## 四、生成友好硬约束（钩子特有的）

1. **钩子必须落得住一张关键帧。** 写钩子的同时写出"这一拍定格成哪张图"。画不出来的钩子改写成画面可见的信息：`电话那头是谁` 画不出来 → `手机屏幕上的来电人姓名` 画得出来。
2. **钩子道具先立项。** 照片、手机屏幕、DNA 报告、遗嘱、验孕棒——都是道具资产。没立项的道具到关键帧阶段只能靠提示词临时发明，一致性必丢（总原则自检第 7 条在这里最容易漏）。
3. **群演是奢侈品。** 原方法论里"围观者的反应是爽感放大器"——H3 画群像弱。放大器降级：用 1–2 个具名角色的反应替代全场震惊，或改成主角独角戏式反应。
4. **时间跳转有账单。** 倒叙/闪回/重生 = 同角色多套妆发 + 多个空间。用之前先数资产，单集尽量只用一条时间线。

## 五、钩子自检（送审前自跑，人工判断不评分）

1. 前 3 秒这张关键帧，不解释剧情观众也会好奇吗？
2. 钩子是哪一型？和前几拍/前几集重复了吗？
3. 信息量对吗？给太少没人想知道；给太多观众自己把答案猜完了。
4. 钩子道具立项了吗？
5. 有下一集吗？没有就别留悬念钩——单集用定格收束，钩子悬空等于烂尾。
