# 剧目素材：融化的冰棍（工作名）

## 一句话梗概
放学路上的女生舍不得浪费最后一口，专注地吮着已经快融化的冰棍——结果冰棍还是从手里滑出去，掉在了地上。

## 立项参数（用户已确认，写进契约）
- 视觉风格：写实电影感（真人质感、自然光、浅景深、轻微颗粒，生活纪实质感）
- 画面比例：9:16 竖屏
- 预计成片时长：6–8 秒（**1 个生成单元**，全片就这一个节拍）
- 对白语言：中文

## 人物设定（用户选定 C 版·校园感）
- 女主（唯一角色）：亚洲女生，学生气、清新。
- 发型：齐肩短发。
- 服装：背带裤（或校服），日常学生装扮，夏日感。
- 气质：干净、真性情，为一口冰棍全神贯注的样子要有可爱的生活感。

## 场景
放学路上：夏日午后的街边/人行道，树影斑驳，阳光明亮偏暖。背景有轻微虚化的街景。

## 唯一的节拍（全片核心，必须完整拍完）
1. **贪恋**：她握着冰棍，专注地吮吸/舔舐已经快融化的部分，全神贯注，甚至有点舍不得松口——这是"贪恋"的表演核心，要拍出她对这口的执念。
2. **临界**：冰棍在她手里已经软了、往下滴，她意识到快吃完了 / 快握不住了（一小段紧张）。
3. **落空**：冰棍从手里滑脱，**掉在地上**。
4. **收尾**：落在她看着地上那根冰棍的反应上（惋惜/懵/无言），情绪轻、不出戏，是这个小悲剧的笑点落点。

## 格式要求（解析器只认这些写法，必须严格遵守）
- **场次头**：写成单行 `第一场 外景 <地点> <时间>`。地点用简短具体名词（如 `街边人行道`），时间只从 `清晨 / 午后 / 黄昏 / 夜晚` 里选一个，放在地点之后。
- **台词**：必须写成**同一行**的 `角色名：台词`（全角冒号），例如 `女生：……啊。`。
  **禁止**把说话人单独写一行、台词写在下一行 —— 那种写法不会被识别成台词，会掉进动作层。
- **动作行**：直接写叙述句即可。

## 创作要求
- **6–8 秒是硬约束**：全片只允许 1–2 个场次，动作节拍要极其精简，不能铺陈背景或加无关人物。
- **台词只保留一句极短的中文感叹**（口播时长不超过 1.5 秒），必须用上一节的冒号格式；内容与"吮冰棍"的口部动作不冲突，且只能出现一次。
- 冰棍是反复出现的核心道具，必须写清楚它的状态变化（完整 → 软化滴水 → 只剩一小截 → 落地）。
- 结尾就落在"冰棍掉在地上"之后的女主反应上，不要加旁白式总结，不要额外反转。
- 不要分镜、不要提示词、不要任何技术字段，只写可拍摄的剧本正文（场次 + 动作 + 台词）。
