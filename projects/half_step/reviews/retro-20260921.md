## 这一轮做了什么

用户给一句点子：「一个可爱的小动物在跳舞，其它你自由发挥」。做成一部**无台词的独舞短篇**：

```
立项 Brief → 剧本(agent_draft) → 板子 → 摄影契约 → 导演稿(agent_draft) → 编译
→ 3 件资产 → 3 张关键帧 → 3 段视频（逐段人工确认）→ 合成 → final 票
```

- 剧名《跳到一半》；**9:16 竖屏**；精致 3D 卡通；黄昏低机位暖光；3 单元。
- 主角：一只毛茸茸的橙红小狐狸（`species: fox_anthropomorphic`），深蓝细围巾。
- 故事：偷练（左右张望、抬爪试探）→ 起劲（原地转两圈、尾巴甩弧）→ 亮相定格 → **身后灌木枝条先动、再一声响** → 耳朵贴后、屈膝压低蹲下。
- **全片 0 句台词**；配乐 `meta.music` = 活泼可爱调皮的卡通配乐。
- 成片：`out/final.mp4`（**480×864 / 9:16 / 16.53 秒 / 5.48 MB**）。全程本地通道，**零元**。
- 规模对比上一部：资产 **12 → 3**、单元 **4 → 3**、参考位 3 → 2（关键帧）。

plan 的「生成」时长 = `max(5.17, 内容)`，而实际 H3 落在 **141 帧 = 5.875s**。

所以 F8 的危害集中在"**含台词的短片**"上；无台词片几乎不受影响。
