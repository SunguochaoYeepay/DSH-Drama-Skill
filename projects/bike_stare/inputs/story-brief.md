# 剧目素材：看呆了

## 一句话梗概
午后草地小径，一个女生弯腰去捡草里的东西；身后骑车的男生看呆了、忘了看路，连人带车翻出画面。

## 立项参数（用户已确认，写进项目契约）
- 视觉风格：**写实电影感**
- 画面比例：**9:16 竖屏**
- 预计成片时长：**约 12–15 秒（1 个生成单元）**
- 对白语言：**无对白（全片无台词）**
- 参考资产：无（`inputs/references` 为空）

## 角色（两人，都必须显式写 `species`）
1. **女生**（画面主体）：二十出头，东亚人，长黑发扎起，浅灰紧身瑜伽裤 + 亮色细吊带 + 运动鞋，入耳耳机。
2. **男生**（配角）：二十出头，东亚人，短发，短袖 T 恤 + 束脚休闲裤 + 帆布鞋，骑一辆共享单车。

## 内容边界（不可打折）
- 全程**衣着完整**，不出现暴露、走光、刻意身体特写或慢放。
- **镜头不替男生"凝视"**：不让摄影机去舔身体部位。笑点落在**他自己出事**，不落在她的身体上。
- 女生弯腰捡东西是**日常动作**，拍得利落自然。

## 场景
午后草地缓坡，一条碎石小径斜穿画面，两侧齐膝野草，远处一排低矮的树。日光偏顶光、硬阴影，空气里有浮尘。

## 剧情结构（建议执行）
1. 开场：女生沿小径走来（**已在画面内**），低头看见草里有东西，停下。
2. 她弯腰去捡 —— 日常、利落。
3. 小径后方，骑车的男生驶过，头扭过去看，眼睛睁大。
4. 车把开始左右摆，前轮蹭向路基；他的视线还黏着，完全没看路。
5. 前轮卡住，连人带车向画面外侧翻倒，**人和车一起跌出画面**。
6. 收尾：女生直起身，看了一眼空掉的小径，继续往前走；草地恢复安静。

## 硬性要求（工程约束，与剧情同等重要）
- **全片无台词**：台词搬运机制不参与本片。
- **一个生成单元最多一个高风险状态转换**（见 `references/directing.md`）：所以开场**两人都已在画面内**，不做"走进画面 / 驶入画面"这类主体进入；全片唯一的高风险转换是结尾男生的**翻倒 + 跌出画面**。
- **不单独立自行车道具资产**：本地关键帧参考图上限 3 张（场景 1 + 人物 2），自行车写进男生造型与场景描述，不占道具槽位。

## 输出格式（机器解析契约，与剧情无关但必须遵守）
1. 剧名**单独一行**，不要写"第一集 XXX"。
2. 场次头**独占一行**且必须含「场次」二字，照这个形状：`场次一 外景 草地小径 白天`。
3. 每个画面/动作**独占一行，以 `△` 开头**；一行只写一个动作。
4. **无台词行**（本片没有对白）。
5. 结尾独立一行 `（完）`。
6. 不要输出解释、标题层级或 Markdown 围栏。
