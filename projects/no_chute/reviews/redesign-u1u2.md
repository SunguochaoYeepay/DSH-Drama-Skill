## 问题

成片读起来是「**上来先说人、然后飞机才掠过**」，而剧本场次一写的是：

```
12 | △ 一架漆面斑驳的螺旋桨飞机从画面右侧飞进来，螺旋桨转成一片模糊的圆盘。
```

**顺序正好相反**，观众读到的因果不连贯。（用户 2026-09-20 评审）

## 原因

u1 的 `why` 里写得很清楚：「伏笔必须落在 0 秒关键帧里 —— 只有首帧会被身份图和后续所有单元反复锚定，放在第二镜里会被推近动作带过」。

于是导演把**两人提到了首帧主体**，把飞机挪到第二个镜头 —— **叙事顺序被 0 秒首帧的锚定约束改写了**。这条约束本身没错，错在用它牺牲了顺序。

**这与 `pot_hit`（2026-09-20）的花盆"从她后面飞上来"是同一类**：0 秒首帧的约束悄悄改写了叙事或物理，而且不报错。规则已回流到 `references/directing.md` 的「建立镜头与 0 秒首帧冲突时，不要为首帧牺牲叙事顺序」。
